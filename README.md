# Arthem — загрузки

Arthem меняет оформление Linux на **Windows XP, 7, 10, 11** или **macOS** и возвращает обычный Linux одной кнопкой.
Работает в **KDE Plasma**, **GNOME** и **Cinnamon**.

## Скачать

Последняя версия — в разделе [Releases](https://github.com/WeiterTrade/arthem-releases/releases/latest).

| Система | Файл | Установка |
|---|---|---|
| Ubuntu, Linux Mint, Debian, Pop!_OS, Zorin | `arthem_*_all.deb` | двойной клик или `sudo apt install ./arthem_*_all.deb` |
| Fedora | `arthem-*.noarch.rpm` | двойной клик или `sudo dnf install ./arthem-*.noarch.rpm` |
| openSUSE | `arthem-*.noarch.rpm` | `sudo zypper install ./arthem-*.noarch.rpm` |

После установки окно Arthem откроется само; программа также есть в меню приложений.

## Горячие клавиши по умолчанию

`Ctrl+Alt+Shift+1` — XP, `+2` — 7, `+3` — 10, `+4` — 11, `+5` — macOS, `+0` — обычный Linux, `+Пробел` — следующий стиль.
Сочетания можно поменять в программе.

## Удаление

`sudo apt remove arthem` или `sudo dnf remove arthem`. Перед удалением оформление в открытых сеансах вернётся к исходному.

Arthem — бесплатная программа. Windows — товарный знак Microsoft, macOS — товарный знак Apple; Arthem с ними не связан.
