**Новое: своё меню «Пуск» для Cinnamon.**

- Пять раскладок, как в оригинале: Windows XP (две колонки, синие шапка и подвал, зелёная кнопка «пуск»), Windows 7 (стеклянная рамка, поиск, тёмная правая колонка), Windows 10 (список программ и плитки), Windows 11 (по центру, сетка закреплённых, «Рекомендуем»), macOS (меню в строке сверху).
- Внутри настоящие данные: все программы, поиск, избранное, папки пользователя, недавние файлы, выход и выключение.
- Arthem сам переключает раскладку вместе со стилем; «Вернуть Linux» возвращает стандартное меню Cinnamon.
- Проверено в настоящем Cinnamon (Ubuntu 24.04) на виртуальном экране.

**Установка:** Ubuntu / Mint / Debian — файл `.deb`, Fedora / openSUSE — файл `.rpm`. Поверх 0.1.0 ставится обычным обновлением.
