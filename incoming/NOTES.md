Первая версия Arthem.

- Стили **Windows XP, 7, 10, 11** и **macOS** для KDE Plasma 5/6, GNOME и Cinnamon, возврат к обычному Linux одной кнопкой.
- Горячие клавиши `Ctrl+Alt+Shift+0…5` и `+Пробел`, свои сочетания с защитой от системных.
- Наборы `.arthem`: импорт оригинальных ресурсов из своих ISO-образов Windows (обои, звуки, иконки, курсоры, кнопка «Пуск»).
- Окно: «Галерея», «Витрина», «Компактный»; темы Aristocrat Классика, Бирюза, Рубин, Аниме, Светлая.

**Установка:** Ubuntu / Mint / Debian — файл `.deb`, Fedora / openSUSE — файл `.rpm`.
